# Third-party credits

BugProof uses FastAPI, Starlette, Uvicorn and Jinja for its web application;
Pydantic for validation; SQLite for persistence; HTTPX and the Python MCP SDK
for transport and protocol support. Exact package versions are in `requirements.lock`.

Google Gemini supplies structured AI proposals. fastn MCP connects the controlled
Google Gmail and GitHub accounts. Alternate Clouds hosts the running application;
GitHub Actions builds the image and GitHub Container Registry stores it.

Project-local planning/development skills include
[gstack](https://github.com/garrytan/gstack) and
[Matt Pocock's skills](https://github.com/mattpocock/skills).
Their retained license files are under [docs/licenses](docs/licenses/).

The order service and support reports are synthetic fixtures created for this
demonstration. Their results establish the stated test conditions, not a real
customer incident. Participant social posts must be written by the participants.
