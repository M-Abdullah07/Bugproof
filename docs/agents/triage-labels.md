# Triage labels

The participant selected the default labels. All five exist in GitHub.

| Role | GitHub label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Will not fix | `wontfix` |

`ready-for-agent` describes specification readiness. It grants no permission
to resume implementation while the participant's explicit hold remains active.
